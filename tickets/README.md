# IT Support Ticket Documentation

This directory contains simulated help desk tickets created as part of my IT support home lab.

Each ticket documents a reported technical issue, the troubleshooting process, diagnostic findings, recommended resolution, and verification steps.

## Ticket Index

| Ticket | Issue | Category | Status |
|---|---|---|---|
| [Ticket #001](ticket-001-windows-slow-performance.md) | Windows computer running slowly | Windows Support | In Progress |

## Documentation Standards

Each ticket aims to include:
- User-reported symptoms and business impact
- Initial troubleshooting hypotheses
- Diagnostic steps and observations
- Findings and root cause, when established
- Resolution or recommended next steps
- Verification and closure notes

**Note:** These tickets are educational simulations. Simulated scenarios and observations are identified as such and are not presented as real workplace experience.
