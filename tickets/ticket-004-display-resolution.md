# Ticket 004: Display Resolution Troubleshooting

**Environment:** SysDesks ticketing simulation  
**Category:** Hardware > Display  
**Tier:** Tier 1  
**Status:** Resolved

## 1. Reported Issue
The user reported that text appeared excessively large and blurry when connecting their computer to a conference room projector. They needed the display configured correctly before a presentation.

## 2. Troubleshooting Steps
1. Connected to the user's device through a remote session.
2. Opened the display settings.
3. Identified that the device was configured to use a low display resolution.
4. Changed the display resolution to 1920 × 1080.

## 3. Root Cause
The device was configured to use a display resolution that was too low for the intended display setup.

## 4. Resolution
Changed the display resolution to 1920 × 1080 to improve display clarity and provide an appropriate resolution for the presentation.

## 5. Verification
The user checked the display and confirmed that the issue was resolved.

## 6. Skills Demonstrated
- Display configuration
- Hardware and peripheral troubleshooting
- Remote support
- Operating system settings
- Resolution verification and user communication

## 7. Lessons Learned
Incorrect display resolution settings can cause text and other content to appear excessively large or unclear. Checking the current resolution and selecting an appropriate supported setting is a practical first step when troubleshooting display quality.
