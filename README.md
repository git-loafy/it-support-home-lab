# IT Support Home Lab

## About This Project

This repository documents my hands-on learning journey in IT support, systems troubleshooting, networking fundamentals, and technical documentation.

I'm developing practical skills through structured labs and simulated help desk scenarios while studying foundational IT concepts.

## Project Goals

- Practice systematic troubleshooting and problem-solving.
- Develop familiarity with Windows and common IT support tools.
- Document technical investigations and their findings.
- Learn how to create clear, professional help desk ticket records.
- Build foundational knowledge for entry-level IT support roles.

## Repository Contents

| Directory | Description |
|---|---|
| `tickets/` | Simulated help desk tickets, incident reports, and troubleshooting records |
| `windows-support/` | Windows operating system diagnostics, configuration, and support procedures |
| `networking/` | Networking fundamentals, IP addressing, connectivity diagnostics, and network troubleshooting |
| `linux/` | Linux command-line fundamentals, file permissions, system administration, and troubleshooting |
| `asset-management/` | IT asset inventories, device tracking, hardware records, and lifecycle documentation |
| `troubleshooting-guides/` | Step-by-step technical guides, diagnostic workflows, and reusable problem-solving procedures |
